# BendMaster Pro
Standalone Android parity rebuild of the BendMaster Pro Base44 calculator.

## v0.1
- Offline calculator
- Bend allowance / bend deduction
- Press-brake tonnage and +15% recommendation
- Shortest flange and die rule-of-thumb
- Flat-pattern calculator
- Local material library
- FAQ / glossary
- No Base44 login or backend

GitHub Actions builds a debug APK on every push to main and on manual dispatch.

**Engineering note:** v0.1 is a parity/testing build. Verify calculations and material properties before production use.
